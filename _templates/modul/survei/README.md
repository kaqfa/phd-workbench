# Modul: survei

**Untuk:** penelitian berbasis kuesioner.

**Tambahkan ke setiap RQ survei:**
- `instrumen/`: kuesioner versi final + riwayat versi, sumber item (adaptasi dari instrumen terdahulu, beserta sitasi)
- `validasi-instrumen.md`: uji validitas & reliabilitas (expert judgement, pilot, Cronbach's alpha, dsb.)
- `rencana-sampling.md`: populasi, kerangka sampel, teknik, ukuran sampel & dasar perhitungannya

**Aturan tambahan:** respons mentah diperlakukan sebagai data sensitif bila memuat identitas.
