# Modul: kualitatif

**Untuk:** wawancara, studi kasus, grounded theory, analisis tematik.

**Tambahkan ke setiap RQ kualitatif** (`05-riset/rqN-*/`):
- `instrumen/`: panduan wawancara, lembar persetujuan (informed consent)
- `transkrip/sensitif/`: transkrip asli (di-ignore Git); `transkrip/anonim/` untuk versi anonim
- `codebook.md`: kode, definisi, contoh, dan riwayat perubahan
- `inter-rater.md`: prosedur dan nilai kesepakatan antar-rater (mis. Cohen's kappa)

**Aturan tambahan:** kutipan partisipan di naskah harus anonim dan tidak bisa dikenali dari konteksnya.
