# Administrasi Studi

**Isi:** Berkas administratif: regulasi kampus, pendaftaran/beasiswa, data calon promotor, izin etik, dan berkas seminar/ujian.

**Kapan dipakai:** Sejak awal. Taruh pedoman resmi kampus di `regulasi-kampus/` secepatnya, karena gate formal (jumlah publikasi, format naskah) hanya boleh diisi dari sana.
